# 1分で世界を救え

YouTube Shorts視聴の代替として遊ぶ、1分以内で完結するオートバトラーゲーム。「運と才能」がテーマで、プレイヤーは操作せず、ガチャで決まった勇者が自動で世界を救う(または救えない)様子を見届ける。

## 遊び方

- ブラウザで `index.html` を開き(またはGitHub Pagesの公開URLにアクセスし)、「はじめる」をタップするだけ
- 才能・運はプレイ開始時に自動で決まり、その結果に応じて勇者が敵を倒しながら進む
- 演出のために結果を調整することはない。制限時間内に敵を倒しきれなければそこで敗北し、どこまで行けたかが結果として残る

## 開発時に参照するドキュメント

- [`SPEC.md`](SPEC.md) — 確定仕様・現在のバランス数値・未確定事項をまとめた唯一の仕様書。仕様を把握したいとき・変更したときは必ずここを参照/更新する
- [`CLAUDE.md`](CLAUDE.md) — このプロジェクトで作業する際の指示書(立場・進め方の原則など)

## 技術構成

- 単一 `index.html`、外部依存なし
- 縦画面(スマホ縦持ち想定)専用レイアウト
- 画像アセットは全てbase64インライン埋め込み
- `tools/balance_sim.js` — Node実行専用のバランス検証用モンテカルロシミュレーション(`node tools/balance_sim.js`)

## デプロイ

masaki0510名義のGitHub Pagesに `index.html` をブラウザアップロードして公開する運用。
